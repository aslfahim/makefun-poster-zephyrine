ZEPHYRINE — a travel poster in the old lithograph manner for a skyport
chained above a canyon, where the balloons come in to dock at dusk. One
Node program paints it from raw pixels: a flat cream sky, strata bands of
red canyon rock, a timber docking mast with a lantern-lit platform, a great
striped balloon chained to the masthead, two smaller balloons, and an
airship on approach — all inside a printed double-rule plate frame. The
port's name is set in hand-drawn stroke letters in red-brown ink. It writes
one PNG to /output/entry.png.

## Run it

```sh
node main.ts
```
